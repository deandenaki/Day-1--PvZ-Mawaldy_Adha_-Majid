# Dokumentasi Workshop Day 1

**Tema:** Building with AI, Managing Change with GitHub

## 1. Rangkuman Materi Workshop

Di workshop hari pertama, materi yang dibahas adalah tentang penggunaan AI untuk membantu
membuat aplikasi dan juga pengenalan Git dan GitHub.

Pertama, pemateri menjelaskan tentang prompt engineering. Jadi, prompt itu adalah instruksi
yang kita berikan ke AI supaya AI bisa menghasilkan jawaban atau sesuatu sesuai dengan yang
kita inginkan. Saya belajar kalau memberikan prompt tidak cukup hanya dengan perintah
singkat. Kita juga perlu memberikan konteks supaya AI lebih paham apa yang ingin kita buat.

Ada juga cara membuat prompt yang lebih jelas, yaitu dengan menentukan Role, Task, Context,
dan Format. Contohnya, kita bisa meminta AI berperan sebagai programmer, menjelaskan
aplikasi yang ingin dibuat, memberikan fitur yang dibutuhkan, lalu menentukan hasil seperti
apa yang kita inginkan.

Setelah itu, materi dilanjutkan dengan pengenalan Git dan GitHub. Git adalah alat untuk
mencatat perubahan pada project, sedangkan GitHub adalah tempat untuk menyimpan repository
Git secara online. Jadi, keduanya saling berhubungan tetapi memiliki fungsi yang berbeda.

Kami juga belajar beberapa perintah dasar Git seperti:

- `git init` untuk membuat repository baru.
- `git add .` untuk memasukkan perubahan ke staging area.
- `git commit -m "message"` untuk menyimpan perubahan.
- `git push origin main` untuk mengirim perubahan ke GitHub.
- `git pull origin main` untuk mengambil perubahan dari GitHub.
- `git clone` untuk mengambil repository dari GitHub ke komputer.

Selain itu, pemateri juga menjelaskan tentang SSH key yang bisa digunakan untuk menghubungkan
komputer dengan GitHub. Kami diperlihatkan cara membuat SSH key dan menambahkannya ke akun
GitHub.

Di akhir materi, kami diarahkan untuk membuat project sederhana bernama Student Task Planner
dengan bantuan AI. Setelah aplikasi dibuat, project tersebut dimasukkan ke Git dan di-push ke
GitHub. Jika ada perubahan pada aplikasi, kita bisa melakukan commit dan push lagi.

## 2. Poin Penting atau Pengetahuan Baru

Beberapa hal yang saya dapatkan dari workshop hari ini:

   agar hasilnya sesuai dengan kebutuhan.
2. Saya baru mengetahui bahwa ada struktur Role, Task, Context, dan Format untuk membantu
   membuat prompt.
3. Saya jadi lebih memahami perbedaan Git dan GitHub. Sebelumnya mungkin saya menganggap
   keduanya sama, ternyata fungsinya berbeda.
4. Saya belajar tentang working directory, staging area, dan repository dalam proses kerja
   Git.
5. Saya mulai memahami fungsi commit, push, dan pull, yang ternyata memiliki kegunaan
   masing-masing.
6. Saya juga belajar bahwa SSH key bisa digunakan untuk menghubungkan komputer dengan
   GitHub.
7. Ternyata AI bisa membantu kita membuat aplikasi lebih cepat, tetapi hasilnya tetap harus
   diperiksa lagi dan tidak boleh langsung dianggap benar.
